# WorkspaceShopCustomer


## Лабораторна робота №1. Робоче місце продавця магазину

### Опис предметної області
Програма імітує робоче місце продавця. Ключова сутність — **Товар**, який продається покупцю. 
Програма дозволяє ввести назву, категорію, ціну та кількість товару, а також враховує наявність дисконтної картки у покупця для розрахунку фінальної суми чека.

### Використані технології
* Java (базовий синтаксис, змінні, оператори розгалуження)
* java.util.Scanner (введення даних)
* System.out.printf (форматоване виведення)

### Інструкція запуску з CLI
1. Відкрити термінал у кореневій папці проєкту.
2. Скомпілювати файл:
   ```bash
   javac SellerWorkplace.java
